Bouwen op LeRobot

LeRobot van Hugging Face is de motor onder Mushin lab: het regelt robotbesturing, data, modellen en evaluatie, zodat wij ons richten op de agent en de klant.

Samenvatting

LeRobot1 levert al de robot-interface, het datasetformaat, de modellen, evaluatie en plugins voor andere robots. De licentie is Apache 2.0, dus we mogen er commercieel op bouwen. Onze waarde zit erboven: de agent die de keten regelt en een werkend proces voor de eerste toepassing.

2Wat dit betekent voor ons

Pad naar de klant bestaat al

Wat we op de SO-101 bouwen, kan via een plugin naar een UR-arm bij een plaatbewerker.

Klaar voor vibecoding

De repo bevat een CLAUDE.md en AGENTS.md, dus coding agents begrijpen de codebase direct.

Onze waarde zit erboven

LeRobot is gereedschap; Mushin lab is de agent die de hele keten regelt plus een werkend proces voor de eerste toepassing.
